# Physics-Guided Neural Dynamics for Pantograph–Catenary Contact Force Estimation

**PGND** is a research project for estimating pantograph–catenary contact forces with physics-guided continuous-time neural dynamics. This repository currently provides only the initial project skeleton; the model, training procedure, and evaluation workflow are not yet implemented.

## Installation

```bash
python -m pip install -r requirements.txt
```

## Data

Place local experimental measurement data in `data/`. See `data/README.md` for details.

## Training

The training entry point is `src/train.py`. The training pipeline is not yet implemented.

## Evaluation

The evaluation entry point is `src/evaluate.py`. The evaluation workflow is not yet implemented.
